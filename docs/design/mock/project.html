# write-up

This is example text showing how a longer write-up reads. The real one would be yours, in your own words.

Context

Teams needed new environments every few weeks, and each request went through a ticket queue and a person who knew which settings to copy. The estate had grown one subscription at a time, so no two were quite the same.

What I built

  • Landing zone in Bicep: management groups, networking and shared services as code.
  • Guardrails: Azure Policy assignments that deny what shouldn't exist, rather than reporting on it afterwards.
  • Subscription vending: a pull request with a short config file is all a team needs to raise.

What I'd do differently

Bring the application teams in earlier. The guardrails were right, but the first version blocked two legitimate patterns that a single conversation would have surfaced.
